# GPThink
A recursive self-feedback loop flopping between the role of "questioner" and "answerer" to create a dialogue of self-propagating thought on any topic.


-----------


To use:

1) Save index.js to a folder.
2) Open CLI (eg Terminal), and cd to that folder (type "cd " and then drag the folder into your command line)
3) Install the following packages with npm command: `npm install openai readline`
4) Edit index.js and add your openAI API key under the configured variables section.
5) Run the command in CLI: `node index.js`
6) Enjoy!
